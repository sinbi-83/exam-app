## 4. 태훈이 사이트에서 확인할 것

1. **왼쪽 메뉴**: 자료 / 시험 출제 / 시험 관리 / 학생관리 / 운영관리 / 알림 이 보인다. 휴대폰 메뉴(☰)도 같고, 자료 > 지문 안에 외부지문이 있다.
2. **옛 주소**: 주소창에 `/exams` 를 치면 시험 관리 > 시험지 보관함으로, `/vocab-test` 는 시험 출제 > 단어 시험으로 넘어간다. 시험지 보관함에서 아무 시험이나 눌러 상세 → 인쇄가 열린다.
3. **단어 시험 레벨 버그**: 시험 출제 > 단어 시험 → 학년 고르고 "단어 자동 선택" → 미리보기 옆 파란 표시가 "중1 학교형 · 영→한 기준 (난이도 15~35)" 식으로 나온다. 레벨을 바꾸면 미리보기가 사라지고, 다시 누르면 새 레벨 기준으로 나온다.
4. **문항 검색 인쇄**: 자료 > 문제은행 > 문항 검색 → 검색 → 인쇄 → 빈 종이가 아니라 문제가 나오고, 쪽 아래에 카피라이트 한 줄이 있다.
5. **1,000개 제한**: 자료 > 단어은행 → 확인 필요 목록이 1,000개에서 끊기지 않는다 (확인 필요 1,920개).
6. **카피라이트**: 화면 맨 아래 "© 2026 보스턴S영어 · 서향미". 외부지문·출석·숙제·채점·원비 화면에는 없다. 단어은행·문제은행에는 "무단 복제·배포 금지" 문구가 있다.
7. **명칭**: 설정 화면에 "교습소 이름", 앱 상단에 "보스턴S영어 관리 시스템".

## 5. 향미 선생님이 할 일 (순서대로)

1. **검수 샘플 보기**: `docs/stage4-review-pack.md` 2장(무작위 샘플 40개)과 3장(애매한 단어 29개)을 훑어본다. 사이트에서는 자료 > 단어은행 → '확인 필요'로 걸러서 본다.
2. **색 이름 결정**: black(검정)·red(빨강) 같은 색 9개에 명사 뜻(검정, 빨강 …)을 정답으로 인정할지 정한다. "인정" → Claude Code에 "색 이름 되돌려 줘"라고 하면 `scripts/restore-color-meanings.ts` 로 백업 후 적용한다. **일괄 사용하기 전에** 정해야 간단하다 (사용 중이 된 뒤에는 선생님 확인 항목을 바꾸는 일이 된다).
3. **일괄 사용하기**: 자료 > 단어은행 → 확인 필요 목록에서 단어를 고르고 **"선택한 N개 사용하기"** → 확인 창에서 진행.
