# 시험지 인쇄 모양 메모 (문제·혼합 시험 일반 인쇄)

- 작성: 2026-09-29 · 대상: `app/tests/[id]/print/` (단어만 있는 시험의 `WordTestPrint` 는 바꾸지 않음)
- 저장된 문항(question_data snapshot)·저장 구조는 그대로. 화면·인쇄 모양만 바꿈.

## 1. 조사 (바꾸기 전, 배포된 코드 기준)

| 항목 | 바꾸기 전 |
|---|---|
| 그리는 방식 | `page.tsx` 한 파일. 시험지 전체를 **세로로 긴 `.page` 한 장**에 그리고, 쪽 나누기는 브라우저·PDF 도구에 맡김 |
| 단어 문항(`type: 'word'`) | 일반 문항과 똑같이 한 줄에 하나: 번호 동그라미 + `[단어] 4점` + 제시어 + 밑줄 → 12개면 12줄 |
| 쪽 나누기 CSS | `@media print` 안에서만 `.question-block { break-inside: avoid }`, 정답 장 `break-before: page`. 구역 제목·지문과 다음 문항을 붙이는 규칙 없음 |
| 쪽 여백 | `@page { margin: 0 0 7mm 0 }` (위 여백 0). 긴 `.page` 의 위 안쪽 여백은 **첫 장에만** 적용 → 둘째 장부터 첫 줄이 종이 맨 위 끝에 붙음 |
| PDF 저장 | `html2pdf` 가 `.print-area` 전체를 **한 장의 긴 그림**으로 찍은 뒤 A4 높이마다 잘라 붙임. `pagebreak: avoid-all` 로 요소를 밀어 보지만 그림을 자르는 방식이라 문항 중간이 잘릴 수 있음 |
| 미리보기 | 없음 (화면은 긴 한 장, 실제 쪽 경계를 볼 수 없음) |

**원인 한 줄**: 쪽을 앱이 직접 나누지 않고 긴 한 장을 브라우저·PDF 도구가 A4 높이로 잘라서, 문항(번호·내용)이 쪽 사이에서 갈리고 둘째 장부터는 위 여백이 없었다.

## 2. 바꾼 방식

- **쪽을 앱이 직접 나눈다** (`lib/printPagination.ts`, `app/tests/[id]/print/ExamSheetPrint.tsx`).
  1. 시험지를 덩어리로 만든다: 머리말 / 지문 / 문항(번호·문제·보기·답 칸) / 단어 줄 / 정답 줄.
  2. 화면 밖에서 쪽 안쪽 폭(182mm)으로 그려 덩어리마다 높이를 잰다 (글꼴을 받은 뒤·크기가 바뀌면 다시).
  3. A4 쪽(.sheet, 210×296mm, 안쪽 여백 위 12 · 옆 14 · 아래 14mm)마다 들어갈 덩어리를 정한다.
  4. 그 쪽들을 **화면 A4 미리보기 · 브라우저 인쇄 · PDF 저장이 그대로** 쓴다 → 셋의 쪽 수·쪽 경계가 같다.
- 쪽 나누기 규칙
  - 덩어리는 쪽 중간에서 자르지 않는다 (번호는 앞 장, 내용은 뒷장 → 없음).
  - 구역 제목(단어·정답·정답의 단어)과 지문은 **다음 덩어리와 같은 쪽**에서 시작 (제목만 쪽 끝에 남지 않음, 지문은 첫 문항과 같은 쪽).
  - 교사용 정답은 **새 쪽**에서 시작.
  - 단어 구역은 새 쪽을 강제하지 않는다 (2026-09-29 변경): 앞 쪽 남은 자리에 구역 제목 + 첫 단어 줄이 들어가면 이어서, 모자라면 그때만 새 쪽.
  - 브라우저 인쇄 보조 CSS 도 같이: `.print-block`/`.question-block`/`.word-cell`/`.answer-block { break-inside: avoid }`, 제목 `break-after: avoid`, `.sheet { break-after: page }`, `@page { size: A4; margin: 0 }`.
- 단어 구역: 여러 열(기본 4열, 화면에서 2/3/4열). 칸 = `번호. 단어 (뜻을 쓰시오/영어로 쓰시오)` + 답 밑줄. 배점은 구역 제목에 한 번 (`단어 (문항당 4점)`). 12개·4열 = 3줄.
- 촘촘하게: 문항 사이 3.5mm, 글자 13px, 보기는 짧으면 한 줄·중간이면 2열·길면 한 줄에 하나, 서술형 칸 14mm.
- 저작권 문구: 쪽마다 쪽 안 아래(인쇄·PDF 동일). 학생용에는 정답·해설 없음(정답 구역은 교사용·답안지만).
- PDF 저장: `.sheet` 한 장씩 `html2canvas` → `jsPDF` A4 한 쪽씩.
- A4 미리보기(기본 켜짐): 종이 모양 + 쪽 사이 간격 + `1 / N쪽` 표시. 끄면 쪽을 이어 붙여(점선 구분) 보여줌. 쪽 표시·그림자는 인쇄에 안 나옴.

## 3. 한계

- **한 쪽보다 긴 지문**(또는 덩어리)은 새 쪽에 혼자 두고 그 쪽만 길게 둔다 → 브라우저 인쇄는 그 지문 안에서 자연스럽게 넘어가고, PDF 는 A4 높이로 잘라 붙여 **지문 글 한 줄이 쪽 경계에 걸릴 수 있다**. 이때 화면의 `N쪽` 은 실제보다 적게 보인다.
- 인쇄 창에서 **배율을 100%(기본)** 로 둬야 화면 미리보기와 같다. '페이지에 맞춤'·여백 변경을 하면 쪽이 달라질 수 있다.
- 지문 상자의 회색 배경은 인쇄 창 '배경 그래픽'을 켜야 나온다 (끄면 흰 바탕 + 테두리).
- 단어 칸의 제시어가 길면(4열) 안내 `(뜻을 쓰시오)` 가 다음 줄로 넘어간다 (높이는 다시 재서 반영).
- 단어만 있는 시험(`WordTestPrint`)은 이번에 바꾸지 않았다 (예전 방식: 긴 한 장 + html2pdf).

## 5. 외부지문저장소 인쇄에도 적용 (2026-09-30)

- 대상: `app/materials/passages/external/[id]/print/page.tsx`. 예전에는 긴 한 장 + `@page` 위 여백 0 + html2pdf 잘라 붙이기 → 둘째 장부터 첫 줄이 종이 맨 위에 붙고, PDF 는 문항이 쪽 사이에서 갈릴 수 있었다.
- 쪽 나누는 틀을 `components/A4SheetPrint.tsx` 로 따로 만들어 이 화면에 연결 (시험지 인쇄 `ExamSheetPrint.tsx` 는 건드리지 않음, 같은 `lib/printPagination.ts` 사용).
  - 덩어리: 머리말 / 지문(첫 문항과 같은 쪽) / 문항 / 서술형 제목(첫 서술형과 같은 쪽) / 서술형 / 끝 문구 / 정답(새 쪽에서 시작).
  - 문항 모양·옵션(정답 포함·서술형 포함·태그 표시)은 예전 그대로. A4 미리보기·쪽 수 표시 추가.
- 위 여백: 처음 12mm → 같은 날 요청으로 **20mm** (`A4SheetPrint` 의 `padTopMm`, 외부지문 인쇄만. 시험지 인쇄는 12mm 그대로). 20mm 로 외부지문 18개 모두 다시 확인: 잘림·문항 갈림 0.
- 확인 (Edge headless, The New Girl 4단계 × 학생용/정답 포함): 학생용 4쪽 · 정답 포함 5쪽, 화면 = 브라우저 인쇄 = PDF 저장 쪽 수 같음, 모든 쪽 위 여백 12mm, 잘림·문항 갈림 0, 정답은 새 쪽에서 시작.
- 아직 예전 방식: AI 지문 인쇄, 문항 검색 인쇄, 단어 시험 인쇄.
- 2026-10-03: 위 여백 20 → **25mm** (요청). 그리고 버그 수정: 인쇄 모드가 되면 높이 재기 칸(.no-print)이 사라져 덩어리 높이가 0으로 재지고, ResizeObserver 가 쪽을 다시 나눠 **모든 덩어리가 한 쪽에 몰려 잘리던 문제** → `A4SheetPrint` 의 measure 가 인쇄 중(또는 높이 0)에는 다시 나누지 않음. 확인 (Edge headless, Cotton 학교형 학생용): 화면 5쪽 = 인쇄 5쪽 = PDF 5쪽, 모든 쪽 첫 덩어리 위 25mm.
- 2026-10-05: 위 여백 25 → **20mm(2cm)** (요청). 이때 Vercel 배포 — 그전까지 이 A4 인쇄 방식은 로컬에만 있었다.
