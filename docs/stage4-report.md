## 3. 일괄 사용하기 기능

- `/vocabulary` 목록에 체크 칸 추가 (확인 필요·나중에 결정 단어에만). 머리줄 체크 = 지금 보이는 목록의 확인 필요 전체 선택.
- "선택한 N개 사용하기" → 개수 확인 창 → `POST /api/vocabulary/bulk`.
- 승인 경로 **batch(일괄 승인)**, 교사 확인 시각 기록(교사가 직접 누른 것이므로). 난이도 없음·확인 필요 아님은 건너뛰고 이유를 보여 준다.
- 화면 이름: 승인 경로 batch = "일괄 승인" (예전 "스크립트 일괄 승인" 101개는 1단계에서 이미 다른 값으로 바뀌어 남은 것이 없다).

## 4. 스스로 판단한 것

1. **기능어 43개는 넣지 않았다**: 관사(a, the), 대명사(I, you, he …), 조동사(can, will, may …), 문법 전치사·접속사(at, in, of, to, and, but …), 부정·대답·인사말(no, not, yes, okay, hello, please), be·do. 반대로 **공간 전치사(under, behind, between …), 의문사(what, where …), 수사, because / however 는 넣었다** — 초등 단어시험에 실제로 나오는 말이라서. 목록은 검수 자료 4장.
2. **다의어는 대표 뜻 1개 + 인정 뜻**으로 처리했다. 영→한 채점에서 흔한 다른 뜻도 정답으로 인정되도록 인정 뜻에 넣고, 이런 단어는 한→영 불가로 했다. 품사가 다르고 둘 다 초등 필수인 7개만 두 항목으로 나눴다.
3. **난이도는 초등 구간 1~30 안에서만** 매겼다 (공식 초등 권장 → 새 자 초3~4 ~ 초5~6). 결과적으로 초5 학교형(1~20)에 많이 몰렸다 — 초등 권장 단어 대부분이 기초어라 자연스럽다고 판단.
4. **시험지 예시는 저장하지 않았다** (위 2장 이유).
5. 원본 메모를 "참고 메모"와 "애매한 점"으로 나눠, 판단을 묻는 11개만 애매한 단어로 올렸다 (back, bat, fan, lie, miss, present, goodbye, off, compute, thirst, tire).
