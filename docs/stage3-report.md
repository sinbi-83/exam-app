## 5. 스스로 판단한 것

1. **레벨 범위 숫자는 제가 정한 초안이다.** 설계도는 기준점만 정했으므로, 위 "만든 원칙"으로 레벨 범위를 만들었다. 선생님 승인 전이라 화면에 "초안"으로 표시.
2. **공식 목록의 괄호 안 파생어도 대조에 쓴다.** 처음에는 표제어만 맞춰 보다가 enjoy·mistake·environment 가 "목록에 없음"으로 나와 원본을 확인했다 → 원본이 `joy (enjoy)`, `take (mistake)`처럼 파생어를 괄호에 적는다. 파생어는 표제어와 난이도가 다를 수 있어 **등급 표시는 "joy의 파생어"로 구분**하고, 난이도 구간 자르기에는 쓰지 않는다.
3. **기준표는 계정별 표(user_id + RLS)로 만들었다.** 다른 표와 같은 방식이고, 모든 권한을 우회하는 service role 키 없이 향미 선생님 로그인으로 넣을 수 있다. 수정 정책은 두지 않아 원본 값이 바뀌지 않는다.
4. **CSV 위치**: 처음 `data/official/` 에 두었다가 지시대로 `data/vocabulary/` 로 옮김 (git mv).
5. **주의 — 3단계 배포와 제안표 적용은 같이 해야 한다.** 새 범위표는 새 자 기준인데 DB 단어 값은 아직 예전 중1 기준이라, 범위표만 배포하면 단어시험에 나오는 단어가 어긋난다. 그래서 3단계는 로컬 커밋만 했다.
6. 영구 제외 경고의 "공식 기본어휘 포함"은 이제 기준표에서 찾는다 (표제어 / 다른 철자 / 파생어). 기준표가 없으면 조용히 건너뛴다.
