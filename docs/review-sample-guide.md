# 검수 샘플표 안내 (향미 선생님용)

'확인 필요' 단어를 **일괄 사용하기** 해도 되는지, 40개만 보고 판단하기 위한 표입니다. 각 줄의 **판정** 칸에 **O** 또는 **X** 만 쓰시면 됩니다.

| 파일 | 대상 | 단어 수 |
|---|---|---|
| `docs/review-sample-A.csv` | 초등 권장 + 중·고 공통 | 40 |
| `docs/review-sample-B.csv` | 그 외 (고등 선택과목) | 40 |

- 엑셀로 바로 열립니다 (한글 깨짐 없음). 난이도 구간(1~10 / 11~40 / 41~79 / 80+)별로 고르게, 무작위로 뽑았습니다.
- 뽑을 때 뺀 단어: 선생님이 이미 검수·수정한 단어, 제작 때 '애매'로 따로 표시한 29개, 색 이름 9개(검정·빨강 등 — 인정 뜻을 따로 결정할 예정).

## 무엇을 보나요 (3가지)

1. **대표 뜻**이 그 단어의 가장 흔한 뜻으로 맞는가
2. **인정 뜻**이 모두 **같은 품사**의 뜻인가 (예: 동사 `smell` 의 인정 뜻에 명사 '냄새'가 있으면 X)
3. **난이도**가 너무 어긋나지 않는가 — 1~10 초등 기초, 11~40 초등 고학년~중1·2, 41~79 중2~고2, 80 이상 고3·고난도. 몇 칸 차이는 괜찮고, 구간이 통째로 틀릴 때만 X

`한→영 가능`은 참고용입니다 (같은 뜻의 영어 단어가 여럿이면 '불가'가 맞습니다). 이상하면 메모에 적어 주세요.

## X 를 체크하는 기준

- 대표 뜻이 틀렸거나, 흔하지 않은 뜻이 대표 뜻으로 올라가 있다
- 인정 뜻에 다른 품사의 뜻이 섞여 있거나, 틀린 뜻이 있다
- 난이도가 구간을 넘어 크게 어긋난다 (예: 초등 기초 단어가 60)
- 단어시험에 낼 가치가 없다 (너무 특수하거나 부적절)

애매하면 O 로 두고 메모만 남겨도 됩니다.

## 메모 예시

| 판정 | 메모 |
|---|---|
| X | 대표 뜻을 '포기하다'로 |
| X | 인정 뜻 '냄새'는 명사라 빼기 |
| X | 난이도 60 → 30 정도 |
| O | 한→영은 불가가 맞을 듯 |

## 다 채운 뒤

파일을 저장(CSV 형식 그대로)하고 Claude Code 에게 "검수 샘플 결과 봐 줘"라고 하시면 됩니다.

### 채점 도우미 사용법

```bash
npm run review-sample-result -- docs/review-sample-A.csv docs/review-sample-B.csv
```

- 파일마다 O/X 개수, X 비율, X 단어 목록(메모 포함)을 보여줍니다.
- 판정 기준: **X 가 40개 중 2개 이하면 '일괄 사용하기 가능 (X 단어 제외)'**, **3개 이상이면 '난이도 구간별로 나눠 다시 검토'**.
- 빈칸이나 O/X 가 아닌 값이 있으면 판정하지 않고 알려 줍니다 (O·○·ㅇ, X·× 는 모두 인정).
- 샘플표를 다시 만들려면 `node scripts/review-sample-build.ts` (같은 단어가 다시 나옵니다. **판정을 적은 파일이 덮어써지니 먼저 다른 이름으로 저장**해 두세요).
